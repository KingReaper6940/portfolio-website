# Portfolio Website - Vrishn Viswa Sathyamoorthy

A modern, professional portfolio website showcasing my work as a software developer, entrepreneur, and AI/ML enthusiast. Built with Next.js and featuring a bold, contemporary design with smooth animations and comprehensive project showcases.

## 🛠️ Tech Stack

### Frontend
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Custom components with Radix UI primitives
- **Icons**: Lucide React

### Development
- **Package Manager**: npm
- **Version Control**: Git & GitHub
- **Code Quality**: ESLint, Prettier (configured)

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/KingReaper6940/portfolio-website.git

# Navigate to project directory
cd portfolio-website

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## 🎨 Design Philosophy

This portfolio follows a **neo-brutalist design approach** with:
- Bold, high-contrast colors
- Thick borders and dramatic shadows
- Clear visual hierarchy
- Minimalist yet impactful aesthetics
- Focus on content and usability

## 🚀 Deployment

The website is deployed and can be hosted on:
- **Vercel** (Recommended for Next.js)
- **Netlify**
- **GitHub Pages** (with static export)

```bash
npm run build
# Connect your GitHub repository to Vercel
```
